## 2. 差事发布规范

### 2.1 标题规范
- 标题应简洁明了，不超过20个汉字
- 必须包含差事类型关键词（如"代取"、"排队"、"维修"）
- 禁止使用夸张或误导性标题（如"轻松月入过万"）
- 禁止包含联系方式（电话、微信等）

### 2.2 描述规范
- 描述应当真实、准确、完整
- 必须包含：服务地点、服务时间、工作内容、特殊要求
- 不得包含违法违规内容
- 不得包含歧视性内容

### 2.3 定价规范
- 必须明码标价，不得隐藏附加费用
- 建议参考平台推荐的定价区间
- 对于时长不确定的服务，应采用"基础价+超时加价"模式

### 2.4 安全规范
- 涉及上门的差事，建议发布方确认履约方身份（平台提供人脸识别对比）
- 高价值差事（物品价值>5000元）建议使用平台担保交易
- 敏感时段差事（22:00-06:00）建议发布方注意人身安全
- 禁止发布代写论文、代考等违规服务

## 3. 履约流程标准

### 3.1 标准履约流程
```
发布差事 → 平台审核（自动+人工） → 履约方接单
→ 双方确认 → 执行差事 → 完成确认 → 评价互评 → 资金结算
```

### 3.2 争议处理流程
```
用户投诉 → 平台介入（收集证据） → 在线调解
→ 调解成功（退款/补偿） → 调解失败（仲裁/法务）
```

### 3.3 退款标准
| 场景 | 退款比例 | 说明 |
|------|---------|------|
| 履约方未按时到达 | 100%退款 | 迟到超过30分钟 |
| 履约方未完成任务 | 100%退款+补偿 | 可申请10-50元补偿 |
| 完成质量不达标 | 50%-100%退款 | 根据实际情况判定 |
| 发布方取消（接单前） | 100%退款 | 无违约金 |
| 发布方取消（接单后） | 80%退款 | 扣除20%作为履约方补偿 |
| 不可抗力 | 100%退款 | 双方无责 |
